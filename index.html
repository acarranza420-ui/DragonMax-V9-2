DragonMax Kodi Repository

Stabilization channel for Kodi 21+ and Fire TV Stick 4K Max testing.

Install

In Kodi, add this source:

https://acarranza420-ui.github.io/DragonMax-V9-2/

Then install repository.dragonmax-1.9.3.zip.

Diagnostics

addons.xml · build.json · updates.json · realms.json

The build payload is deliberately not exposed as an installable add-on. DragonMax Wizard handles validated payload installation.
